# Telegram: заявки з сайту і переписка

Оновлено 2026-10-08 під тестове завдання. Два різні механізми:

| Задача | Кнопка на сайті | Через що працює | Стан |
|---|---|---|---|
| 1. Отримання заявок | «Надіслати заявку» (форма) | **Telegram-бот** → повідомлення власнику сайту | код готовий; бот створює власник (нижче) |
| 2. Переписка з клієнтом | «Написати у Telegram» | **особистий Telegram** (посилання `t.me/SerhiiM_UA`), бот не потрібен | вписано 2026-10-08 |

Бот потрібен лише для заявок: він надсилає повідомлення, а не «розмовляє» за
власника. Переписка йде напряму з особистим акаунтом.

Токен бота **ніколи** не кладеться в код чи файли проєкту, лише в секрети
Cloudflare (`TG_BOT_TOKEN`, `TG_CHAT_ID`) або в локальний `.dev.vars` (не в git).

## Частина 1. Заявки з форми в Telegram

### Схема

```
Клієнт заповнює форму: Ім'я*, Телефон*, Що зробити* (+ розрахунок з калькулятора), Фото
        │  браузер перевіряє поля зі * (site/main.js)
        │  POST /api/lead
        ▼
functions/api/lead.js (Cloudflare Pages Functions)   ← токен бота тільки тут, у секретах
        │  повторна перевірка полів, пастка для спам-ботів
        │  Telegram Bot API: sendMessage / sendPhoto
        ▼
Бот надсилає повідомлення власнику (або в групу)
```

### Крок 1. Створити бота (≈5 хвилин, робить власник сам)

1. У Telegram відкрити **@BotFather** → `/newbot`.
2. Назва: наприклад «Заявки — збірка меблів (тест)». Нік має закінчуватися на
   `bot`, наприклад `meblitz_leads_bot`.
3. BotFather видасть **токен** виду `123456789:ABC…`. Нікому не пересилати,
   у чат з Claude і в файли не вставляти.
4. Відкрити свого бота і натиснути **Start** (або написати `/start`). Без
   цього бот не зможе написати першим і chat_id дізнатися не вийде.

### Крок 2. Дізнатися chat_id (≈2 хвилини)

Варіант А: виконати в терміналі:

```bash
sh scripts/tg-check.sh
```

Скрипт попросить вставити токен (ввід невидимий), покаже нік бота і `chat_id`
усіх, хто йому писав, і запропонує надіслати тестове повідомлення. Якщо список
порожній, ще раз натиснути Start у боті.

Варіант Б: відкрити **@userinfobot** → Start → він покаже `Id`.

Якщо заявки приймають кілька людей: створити групу, додати бота і людей,
chat_id групи починається з `-` (його теж покаже скрипт після будь-якого
повідомлення в групі).

Якщо на запит chat_id ввести число, прийде «✅ Тест: бот заявок підключено».

### Крок 3. Локальна перевірка (необов'язково)

Дописати в `.dev.vars` (файл не в git) рядки `TG_BOT_TOKEN=…` і
`TG_CHAT_ID=…`, запустити `npm run dev`, відправити заявку з
http://localhost:8788. Вона прийде в справжній Telegram.

### Крок 4. Секрети на Cloudflare (після публікації, `docs/08-technical.md`)

```bash
npm run secret -- TG_BOT_TOKEN
```

```bash
npm run secret -- TG_CHAT_ID
```

Потім `npm run deploy`. Або в панелі Cloudflare: Workers & Pages → проєкт →
Settings → Variables and Secrets → додати обидві як **Secret**.

### Крок 5. Перевірити на живому сайті

- [ ] Заявка з усіма полями і фото → прийшла з фото.
- [ ] Заявка без фото → прийшла текстом.
- [ ] Заявка з калькулятора (довгий текст + фото) → текст і фото двома повідомленнями.
- [ ] Порожня форма → три помилки під полями, нічого не надсилається.
- [ ] Увімкнути сповіщення для чату з ботом.

### Формат повідомлення

```
🛠 Нова заявка з сайту
Ім'я: Олена
Телефон: 067 123 45 67
Що зробити: Розрахунок з калькулятора:
— Двомісне ліжко × 1 (800 грн)
— Шафа для документів × 2 (від 800 грн)
Орієнтовно: від 1 600 грн
Час: 08.10.2026, 14:32:00
```

### Що вже є в коді (`functions/api/lead.js`)

- Обов'язкові ім'я, телефон (≥ 9 цифр), опис; перевірка в браузері і на сервері.
- Приховане поле-пастка `website` відсіює ботів-спамерів.
- Фото до 5 МБ йде разом з текстом (`sendPhoto`); якщо текст довший за
  1000 символів (ліміт підпису Telegram 1024), текст і фото йдуть окремо.
- Без секретів сервер відповідає 503, клієнт бачить «Не вдалося надіслати.
  Подзвоніть…» з телефоном.
- Заявки ніде, крім Telegram, не зберігаються.

Якщо почнеться спам — додати Cloudflare Turnstile (безкоштовна невидима перевірка).

## Частина 2. Кнопка «Написати у Telegram»

Звичайне посилання `https://t.me/нік` у двох місцях `site/index.html`
(блок «Залишити заявку» і нижня панель на телефоні). Нік у Telegram:
Налаштування → Ім'я користувача. Варіант без ніку: `https://t.me/+380XXXXXXXXX`,
якщо в налаштуваннях приватності дозволено знаходити вас за номером.

Вписано `https://t.me/SerhiiM_UA` (2026-10-08). Щоб змінити, замінити в обох
посиланнях (`grep -n "t.me/" site/index.html`).

## На майбутнє: бот з діалогом

Той самий бот може сам розпитувати клієнта: тип меблів → фото → адреса →
зручний час. Потрібен webhook (`functions/api/telegram.js`) і збереження
стану діалогу в KV.
