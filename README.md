## Що вміє сайт

- **Ціни і калькулятор:** усі групи прайсу відкриті одразу; кнопками «−/+»
  клієнт збирає перелік, бачить «від X грн» і кнопкою «Додати в заявку»
  вписує розрахунок у форму. Калькулятор рахує з того ж прайсу, що
  редагується в адмінці.
- **Заявка в Telegram:** форма (ім'я*, телефон*, що зробити*, фото) →
  `/api/lead` → повідомлення власнику через Telegram-бота. Перевірка полів у
  браузері і на сервері, пастка для спам-ботів.
- **Галерея робіт:** фото з адмінки, тап відкриває на повний екран (стрілки, свайп).
- **Адмінка `/admin`:** прайс, галерея фото (зменшуються в браузері, старі
  видаляються зі сховища), зміна пароля. Хеш пароля PBKDF2, cookie `HttpOnly`,
  блокування після 5 невдалих входів, авто-вихід через 5 хвилин.
- **Демо одним файлом:** `python3 scripts/build-demo.py` → `dist/…demo.html`,
  відкривається без сервера (калькулятор працює, форма нічого не надсилає).

## Як це працює

```
Клієнт ──► сайт (Cloudflare Pages, папка site/)
              │  прайс і фото ◄── /api/content ◄── сховище KV
              │  калькулятор рахує з того ж прайсу
              │  форма заявки ──► /api/lead ──► Telegram-бот ──► телефон майстра
Майстер ──► /admin (логін + пароль) ──► змінює прайс і фото ──► KV
```

Чистий HTML/CSS/JS без фреймворків; серверна частина — Cloudflare Pages
Functions (`functions/`); сховище — KV. Вартість хостингу 0 грн.

## Запустити локально

Потрібен Node.js 18+ (перевірено на v24).

```bash
npm install
```

```bash
npm run dev
```

Сайт http://localhost:8788, план http://localhost:8788/plan, адмінка
http://localhost:8788/admin (локальний логін/пароль `admin` / `admin` з `.dev.vars`). Заявки
локально підуть у Telegram лише якщо в `.dev.vars` вписати токен свого бота
([docs/04-telegram-leads.md](docs/04-telegram-leads.md)); без нього форма
покаже «Не вдалося надіслати», це нормально.

Публікація на Cloudflare: [docs/08-technical.md](docs/08-technical.md).
